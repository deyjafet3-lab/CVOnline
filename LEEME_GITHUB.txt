PORTAFOLIO EN GITHUB PAGES - proyectos automaticos desde la carpeta Proyectos/

CONFIGURACION (una sola vez)
1) En la RAIZ del repositorio deben quedar estos archivos:
      index.html
      generar_proyectos.py
      .github/workflows/publicar.yml
      Proyectos/            (tus carpetas de proyectos)
   Si al arrastrar la carpeta ".github" no se sube, usa: Add file > Create new file,
   escribe el nombre  .github/workflows/publicar.yml  y pega el contenido del archivo.
   (Si ya tenias editado tu index.html, copia antes tu bloque <script id="data"...> al nuevo.)
2) Settings > Pages > Build and deployment > Source: elige  GitHub Actions.
3) El repositorio debe ser publico (Pages gratis).

USO DIARIO (sin tocar index.html)
- Add file > Upload files, arrastra la carpeta nueva dentro de Proyectos/ y Commit changes.
- Espera 1-2 minutos (puedes ver el avance en la pestana Actions). El proyecto aparece solo,
  con TODAS las imagenes de la carpeta, sin importar como se llamen (se ordenan por nombre;
  la primera es la portada). El titulo sale del nombre de la carpeta.

OPCIONAL: titulo, categoria, descripcion y link de Behance
- Pon un archivo  info.json  dentro de la carpeta del proyecto:
      {"titulo": "Ennova Brand", "categoria": "Branding", "descripcion": "Texto...", "link": "https://www.behance.net/gallery/..."}

CONSEJOS
- Imagenes de ~1 MB o menos (JPG/WEBP) para que la pagina cargue rapido.
- Desde el navegador GitHub deja subir unos 100 archivos por vez; si son muchos, sube en tandas.
- Si algo no aparece, revisa la pestana Actions: una X roja indica el error.
