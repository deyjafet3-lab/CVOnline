ACTUALIZAR TU PORTAFOLIO EN GITHUB (con la carpeta proyectos/)

Estructura del repositorio:
  index.html
  generar_proyectos.py
  proyectos/
     ennova-brand/foto1.jpg, foto2.jpg ...
     otro-proyecto/...

1) IMPORTANTE: si ya agregaste/editaste proyectos en el index.html que tienes en GitHub,
   antes de reemplazarlo copia tu bloque <script id="data" type="application/json">...</script>
   y pegalo en el index.html nuevo (el formato es compatible).
2) Sube/reemplaza index.html (y generar_proyectos.py) en el repositorio.
3) Para que cada carpeta de proyectos/ aparezca con todas sus fotos:
   - Descarga el repositorio en tu PC (o abre una terminal en la carpeta del proyecto) y ejecuta:
         python generar_proyectos.py
   - Sube el index.html resultante a GitHub (Add file > Upload files > Commit changes).
   El script conserva titulo, categoria, descripcion y link de Behance de lo que ya existe,
   solo actualiza las fotos y agrega las carpetas nuevas.
4) Despues edita titulo/categoria/descripcion/link abriendo tu sitio con /#admin al final.

Nombre de fotos: se ordenan por nombre (foto1, foto2, ... foto10); la primera es la portada.
Tip: usa minusculas y sin espacios en carpetas y archivos para evitar problemas en GitHub Pages.
